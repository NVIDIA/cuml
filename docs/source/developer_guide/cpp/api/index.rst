C++ API Reference
=================

This section contains the Doxygen-generated C++ API reference for cuML,
including interfaces used to build and link ``libcuml``. It is distinct from
the separately published `libcuml Doxygen reference
<https://docs.rapids.ai/api/libcuml/stable/>`_.

.. note::

   This reference is primarily for cuML developers and internal use. The
   interfaces documented here may change without notice and do not carry the
   stability guarantees of the user-facing cuML APIs. Do not assume that
   these internal C++ interfaces provide the input-validation guarantees of
   public Python or other user-facing APIs.
